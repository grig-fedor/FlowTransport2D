# FlowTransport2D

Учебная программа для численного моделирования фильтрации подземных вод и переноса растворённых веществ в двумерной области.

Программа предназначена для изучения методов численного решения уравнений фильтрации и переноса, в том числе явной противопотоковой схемы.

## Возможности

- Стационарная и нестационарная фильтрация.
- Перенос растворённых веществ.
- Задание начальных и граничных условий.
- Моделирование скважин.
- Настройка расчёта через JSON.
- Сохранение результатов в формате VTK.

## Зависимости

- CMake.
- Компилятор с поддержкой C++17 (проверено с MSVC 2022).
- INMOST — включена в `external/inmost`.
- nlohmann/json — включена в `external`.

## Сборка

Проект собирается с помощью CMake. Для Windows сборка проверена в конфигурациях Debug и Release с использованием MSVC 2022.

## Запуск

```text
FlowTransport2D.exe model.json
```

Если путь к конфигурационному файлу не указан, программа использует `model.json` из рабочего каталога.

Результаты расчёта сохраняются в формате VTK.
